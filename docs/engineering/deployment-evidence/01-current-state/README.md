# 01 – Current State Assessment

## Objective

Document the existing Verizon Fios infrastructure before Project Orion implementation changes are made.

## Scope

The assessment covers:

- Verizon Fios Optical Network Terminal
- ONT physical installation
- ONT port connections
- ONT asset identification
- Ethernet cable entry point in the office

## Evidence Collected

| Evidence ID | File | Description |
|---|---|---|
| PO-EV-001 | PO-EV-001_ONT_Exterior_Installed.jpg | Exterior installation of the Verizon Fios ONT |
| PO-EV-002 | PO-EV-002_ONT_Port_Connections.jpg | ONT fiber, Ethernet, coax, and power connection area |
| PO-EV-003 | PO-EV-003_ONT_Asset_Identification.jpg | Verizon ONT identification and regulatory markings |
| PO-EV-004 | PO-EV-004_Office_Ethernet_Drop.jpg | Ethernet cable entry point within the office |

## Findings

- The Verizon Fios ONT is installed in an exterior utility enclosure.
- The ONT is active and connected to the Verizon fiber service.
- An Ethernet connection runs from the ONT toward the interior network.
- The office Ethernet entry point has been identified and documented.
- The existing physical environment can support a staged GL.iNet Flint 2 deployment.
- No physical network changes were made during this assessment.

## Outcome

The existing Verizon Fios infrastructure has been documented as the current-state implementation baseline for Project Orion.
